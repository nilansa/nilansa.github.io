# Personal links

Canonical registry for the public pages linked at [nilansa.github.io/personal-links/](https://nilansa.github.io/personal-links/).

**Maintenance rule:** Whenever a new page is created on nilansa.github.io, add it here and update `personal-links/index.html` in the same change. This Markdown file is the source of truth for page discovery. Verify that the destination exists before linking it; use stable, same-site paths. Do not publish private account details, notebook shares, unpublished manuscripts, tokens, or internal infrastructure.

## Editing checklist

1. Confirm that the new page is published or that its corresponding file exists in `main`.
2. Add one descriptive Markdown link to its appropriate section above.
3. Add the matching visible link under the same section in `personal-links/index.html`.
4. Keep typography and layout restrained and readable, with no decorative slash separators.
5. Review what is public: `noindex` is **not** access control. Never add private URLs or secrets here.
6. Check internal navigation and GitHub Pages deployment before calling it live.
