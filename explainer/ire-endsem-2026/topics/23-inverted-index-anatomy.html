Inverted-index anatomy

The inverted index transposes documents-by-terms into term-to-postings mappings.

High yieldProvided module reference

Basis: M2 pp.24–26. Page labels point to the provided files or named reading; the explanation and exercises here are independently written.

01 / Understand

What actually happens?

A term dictionary locates sorted docID lists; postings optionally hold frequency, positions and fields. Document IDs only support Boolean membership; positions enable phrases; term frequencies support scoring. Choose fields based on likely query operators.

Core principle
The inverted index transposes documents-by-terms into term-to-postings mappings.
