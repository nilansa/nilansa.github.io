Lesson 66 / 69 · A/B testing

Sample-ratio mismatch and data quality

Observed assignment proportions inconsistent with design can signal experiment instrumentation errors.

High yieldSyllabus-derived extension

Basis: End-sem announcement 14 Nov; A/B testing extension. Page labels point to the provided files or named reading; the explanation and exercises here are independently written.

01 / Understand

What actually happens?

If a nominal 50/50 allocation yields a persistent large discrepancy, check eligibility filters, bucketing hashes, exposure events and data loss before interpreting metric lift. Random fluctuation exists, so use an appropriate diagnostic rather than assuming any imbalance is a bug.

Core principle
Observed assignment proportions inconsistent with design can signal experiment instrumentation errors.

Try to reason through the mechanism

  1. Identify what the system is trying to preserve or measure in the situation.
  2. Separate the observed symptom from the cause described in this lesson.
  3. Choose the operation, model or trade-off that fits that cause; name its failure mode.

A concrete case

A treatment gets 65% of eligible user events despite configured 50%; the result might be invalid.
