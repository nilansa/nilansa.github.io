PRIORITY 01

Pick a ranking metric

A support search must put the correct password-reset article first. A shopping search should put several useful products on the first screen.

MRR = mean(1 ÷ rank of first relevant result). nDCG@k = DCG@k ÷ ideal DCG@k. For this guide, DCG = Σ(2^grade − 1) ÷ log₂(rank + 1).

Work it through. Grades [0, 2, 0, 2]: at rank 1 the gain is 0. At rank 2 it is 3 ÷ log₂3. IDCG sorts the same judged items by grade and uses the same cutoff. Dividing by IDCG makes the score relative to the best possible ordering for that query.

Exam rule. Use MRR for the first useful answer. Use nDCG when several results and grades matter. Use recall@k for candidates: an item dropped upstream cannot be recovered by reranking.

PRIORITY 02

Learn what to move up

You already know SGD: a loss tells you how to change a model. Changing the loss changes which ranking errors receive the most work.

For a preferred A over B, let d = score(A) − score(B). Pairwise logistic loss is log(1 + exp(−d)).

Work it through. If d = −1, the loss is about 1.31. If d = +1, it is about 0.31. The derivative −1/(1 + exp(d)) pushes the winning score up and the losing score down. A LambdaRank-style update scales that pair’s push by |ΔnDCG|. With grades [0,2,0,2], swaps 1↔2 and 3↔4 each fix one inversion, but the nDCG gains are about 0.226 and 0.043.

Exam rule. Pointwise fits items separately. Pairwise learns an order. A metric-weighted pair update cares where the error occurs. Do not trade away the candidate set to improve the loss on items you already found.

PRIORITY 03

Separate exposure from relevance

A rank-1 result has twice as many clicks as a rank-6 result. Users may like it more, or they may just see it more often.

Under a simple examination model: P(click) ≈ P(examined) × P(click | examined). The bar means “given that”: the second term asks what fraction clicked among the people who actually looked.

Work it through. A card shown at the top is examined 80% of the time and clicked 25% of those times: CTR = 20%. At the bottom it is examined 40% of the time: CTR = 10%, with no change in appeal. Randomized exposure can help estimate the examination difference.

Exam rule. An unclicked item may be unseen. Raw click logs reflect the old ranker. Check feature timestamps too: a future click count cannot be an input at serving time.

PRIORITY 04

Design an A/B test

A new ranker boosts click-through but may slow responses. The same account can open several sessions.

Choose the randomization unit before rollout. State the primary outcome, guardrails, duration and analysis unit.

Work it through. Assign each account once, compare account-level outcomes, and monitor p95 latency and conversion. Shared inventory can let treatment change control outcomes; consider a cluster design if it does and account for fewer independent units. Interleaving can compare preference quickly, but it is not a substitute for a conversion A/B test.

Exam rule. When both rankers score the same queries offline, use paired differences. When distinct randomized users see A and B online, compare the two groups at the appropriate unit.

PRIORITY 05

Read the result without overclaiming

Control conversion is 10.0%; treatment is 10.3%. The 95% interval for the difference is [−0.2, +0.8] percentage points.

Effect = +0.3 percentage points, or +3% relative. Approximate planning rule at fixed alpha and power: n ∝ variance ÷ MDE².

Work it through. The interval includes zero, harm and benefit: you have not shown equivalence. Halving the minimum detectable effect needs about 4× the sample size. If A yields p=.04 and B yields p=.06, test the difference directly; a threshold crossing in one arm does not establish a difference.

Exam rule. A p-value measures how surprising a result at least this extreme is under the null and test assumptions. It is not the probability that the null is true. Do not stop at the first p<.05 without a valid sequential rule. Report the effect and interval. Define one primary metric up front; adjust or clearly label exploratory comparisons.

15 MIN · 6 MCQs + 1 CHALLENGE

Mini-mock A

Pick one answer. Say why in one line. Give yourself two points per MCQ and four for the challenge. This is a practice scale, not the final’s marking scheme.

  1. A help centre needs one correct setup link quickly. Which metric fits?

    A. MRR   ·   B. recall@100   ·   C. average latency

    Show answer

    MRR. It rewards the rank of the first relevant link.

  2. The exact reranker never sees the best document. What should you improve first?

    A. Reranker loss   ·   B. candidate recall   ·   C. calibration

    Show answer

    Candidate recall. A reranker cannot score a document that was never retrieved.

  3. A is preferred to B, but score(A)−score(B) is negative. What should SGD do to this gap?

    A. Increase   ·   B. decrease   ·   C. preserve it

    Show answer

    Increase it. The pairwise logistic loss falls as the preferred item moves ahead.

  4. Identical cards get more clicks in a higher slot. What is the strongest conclusion?

    A. Higher appeal   ·   B. higher observed clicks   ·   C. higher conversion

    Show answer

    Higher observed clicks. Exposure and appeal are confounded without more evidence.

  5. The same query set is scored using both rankers. How should you bootstrap the difference?

    A. Draw individual documents   ·   B. draw paired queries   ·   C. draw both arms independently

    Show answer

    Draw paired queries. Keep both scores together for each independent query.

  6. A test has p=.18 and a wide interval. Is it evidence the effect is zero?

    A. Yes   ·   B. no   ·   C. only if the sample is large

    Show answer

    No. A wide interval may contain meaningful effects in both directions.

  7. Challenge: You can fix one pair. Swapping the top pair adds .18 nDCG; swapping the lower pair adds .02. Both pairwise losses match. What changes when you use a metric-weighted pair update?

    Show answer

    Weight the first swap 9× as much. The absolute metric change sets the weight; .18/.02 = 9.

15 MIN · 6 MCQs + 1 CHALLENGE

Mini-mock B

Pick one answer. Say why in one line. Give yourself two points per MCQ and four for the challenge. This is a practice scale, not the final’s marking scheme.

  1. A code search returns all useful snippets but puts the strongest last. Which metric detects graded quality near the top?

    A. Recall@k only   ·   B. nDCG@k   ·   C. throughput

    Show answer

    nDCG@k. It uses both graded gain and a rank discount.

  2. Two rankers have the same top-score order but wildly different probability estimates. What can differ?

    A. Calibration   ·   B. order-only AUC by necessity   ·   C. candidate set by necessity

    Show answer

    Calibration. Rank order can stay fixed while probabilities become wrong.

  3. A click feature counts events that occur after the query being predicted. What is the problem?

    A. Position discount   ·   B. leakage   ·   C. cold-start only

    Show answer

    Leakage. The feature uses information unavailable at prediction time.

  4. A user revisits the shop across devices and can see both versions. What is the better assignment unit if sign-in is stable?

    A. Request   ·   B. displayed item   ·   C. account

    Show answer

    Account. Stable assignment reduces contamination across visits.

  5. A team checks daily and plans to stop on its first p<.05. What should it do instead?

    A. Use a fixed horizon or valid sequential test   ·   B. report relative lift only   ·   C. drop the control

    Show answer

    Use a fixed horizon or valid sequential test. Repeated unadjusted looks increase false positives.

  6. All else fixed, you want to detect a change half as large. Roughly what happens to sample size?

    A. 2×   ·   B. 4×   ·   C. no change

    Show answer

    4×. Sample size scales inversely with squared minimum detectable effect.

  7. Challenge: Randomizing shoppers may shift a shared pool of limited stock. What assumption fails, and what change would you test?

    Show answer

    Interference; try a cluster design around separately stocked markets. A user’s treatment can change what controls can buy. Match the analysis to the randomized clusters.
