The same examples, new coordinates

Think of each example as a dot. A layer moves each dot. Moving all the dots changes the shape of the cloud. A network learns a series of moves that make a later task easier, such as separating two classes.

What changes: the numbers that describe each example. What does not: the example and its original label. Chapter 13 calls this a distribution transformation. A distribution tells us where examples tend to sit.

Start with one dimension · §13.2

Mark −2, −1, 1 and 2 on a number line. A shift adds 1 to each point. A stretch doubles its distance from zero. Neither move joins distinct points in this example. A nonlinear rule can do something different: ReLU keeps positive numbers and replaces negative numbers with zero. The two negative points now coincide.

Read each row from the same inputs at the top. Unlike ReLU, sigmoid squeezes values into a range between 0 and 1 without joining distinct finite inputs in exact arithmetic. The chapter’s map view tracks each input to its new location, not just the shape of the function curve.

Now use two dimensions · §13.3

A layer can first mix two coordinates to produce a new pair. Next it can apply ReLU to each new coordinate. Coordinatewise ReLU moves (−2, 1) to (0, 1), (1, −2) to (1, 0), and (−2, −1) to (0, 0). A point already in the positive quadrant stays put. Many input points may pile up on an axis or at the origin.

Use the new features to classify · §13.4

Take four points: (1, 1) and (−1, −1) are positive; (1, −1) and (−1, 1) are negative. No single straight line splits the classes. Compute ReLU(x+y) and ReLU(−x−y), then add them. The new feature is |x+y|. It is 2 for the first pair and 0 for the second pair. A threshold at 1 now separates them. This is a hand-set example; training learns the corresponding feature rules from examples.

Why the loss matters · §§13.3–13.4

A binary classifier can give each example two probabilities that add to 1. The ideal target for class A is (1, 0); for class B it is (0, 1). A loss penalizes a model for putting too little probability on the actual class of each example. Merely producing the right overall mix of class probabilities is not enough: the model must make the right prediction on each example. Precision and recall measure the decisions after you choose a threshold. Backpropagation comes later; it computes how each weight affects the loss.

What a CLIP picture shows · §13.5

In the chapter’s CLIP example, the activation vector shown for an image has 38,400 coordinates. The authors use t-SNE to make a two-coordinate view from selected layers together. Colour marks the known class. The later view shows groups that look more distinct than the earlier view.

Keep the two moves separate. The network first changes the full feature vectors. Then t-SNE makes a separate, approximate display for people to inspect. The display is not a network layer. Nearby marks can suggest local similarities. Do not use the size of a group, its distance from another group, or the path between panels as exact measurements of the original space. To test whether the features help, measure a held-out classification task in the original feature space.

Check yourself

Can you reconstruct an original negative number from a ReLU output of zero? No. Many different inputs map to zero. Can a well-separated t-SNE plot prove that a model has high test recall? No. You need test labels and a fixed decision rule to measure recall.

Takeaway · §13.6. A trained network can reorganize the same examples into more useful coordinates. Track what each step preserves or loses. Use visualization to ask a question, and a measured test to answer it.
