Fit what is left

Find the errors. Fit a small correction. Add it to the current prediction. Repeat only while it helps on new data.

Pass 1 · 30 seconds

Start with one prediction. Fit what it missed.

In 30 seconds. Start with a simple prediction. Find where it is wrong. Fit a small model to those errors. Add part of its prediction to the first prediction. Find the errors again. Each new model sees the errors left by the full stack, not just by the last model.

Pass 2 · 3 minutes

Work through three training rows.

We want to predict the target y from the feature x. Use squared-error loss. Start with the mean target, 2. Find each residual: target minus current prediction. Use a tree with one split for each correction. A leaf of the tree predicts the mean residual of the rows in that leaf. Use a learning rate of 0.5: add only half of the tree output.

Try one row

For x = 1, the second tree outputs −0.75. Will the next prediction go up or down? Will it reach the target 2?

Show this step

It goes down. Add 0.5 × (−0.75) = −0.375 to 2.5. The result is 2.125, so the new residual is −0.125. The tree uses the same correction for both rows in its left leaf.

Now try a learning rate of 1 for the second round only. What would happen to that same row?

Compare the full step

The prediction would be 1.75. It would cross the target and make the new residual +0.25. A full step can still reduce the total training loss across rows; it need not improve every row.

Pass 3 · the formula

Which error does the next model learn?

For half squared error, L(y, s) = ½(y − s)², the negative gradient with respect to the current score s is y − s. For another differentiable loss, compute rᵢ = −∂L(yᵢ, sᵢ)/∂sᵢ at the current scores. Fit the next learner hₘ(x) to these values. They are called pseudo-residuals: they describe which way the score should move. For binary logistic loss with a log-odds score, this value is y − p, where p is the current probability. Add the update to the log-odds, not to the probability.

A line search can choose a scale γ that gives the lowest training loss along the direction of hₘ. In the simple version the update is Fₘ(x) = Fₘ₋₁(x) + ηγhₘ(x). Here η is the learning rate. Shrinkage means use 0 < η < 1 to take only part of that step. The toy uses γ = 1; its trees already predict the mean squared-error residual in each leaf. Some tree methods choose a separate update for each leaf instead of one scale for the full tree.

At prediction time, start with the base prediction and add the trained tree outputs. You do not need the true target to make that prediction. The target was used during training only. This is not a neural skip connection. In this example the learner at each stage corrects a prediction function; it does not edit an internal layer of a network.

Check your model

Stop before it learns the noise.

  • Noise: If the remaining errors are mostly noise, more trees can learn noise. Stop at the round with the best held-out validation result, not at zero training error.
  • A large step: A high learning rate can overshoot. A smaller rate often needs more rounds. Set the rate and number of rounds on validation data.
  • A weak correction: A small tree cannot learn a pattern it cannot split on. A flat validation curve can mean that the features or the model lack the needed information.
  • Data leakage: Keep validation and test targets out of tree fitting. If the base model was trained separately and you plan to fit a second-level correction on its outputs, use held-out or out-of-fold base predictions where appropriate. That is a different procedure from fitting all boosting stages on one training set.
What if the first model is already fitted?

You can freeze it as F₀ and fit a sequence of corrections. If you calibrate on predictions from a base model you trained separately, make those predictions on held-out or out-of-fold rows where appropriate. A second model must learn a repeatable error, not the first model’s memorization. This is different from training standard gradient boosting stages on the same training set.

Primary source: Jerome Friedman, Greedy Function Approximation: A Gradient Boosting Machine (2001).
