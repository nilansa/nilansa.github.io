IndoML Datathon · Technical postmortem

What the validation results taught me

A record of the choices that held up, the experiments that did not, and the difference between a local score and a competition result.

16 October 2026
Scope and score labels. The numbers below come from local evaluations on released, pinned validation manifests and prior recorded evaluations. They are not Phase 2 leaderboard scores. The private Phase 2 leaderboard was not available for a fresh independent check, so this article gives no current rank or leaderboard claim. The 3,178-clip Phase 2 blind package was not used to choose or score these candidates.

I worked on two different problems: finding noise events and improving speech audio. Each problem has its own data, metric and failure mode. The main result was not a winning new model. It was a clearer boundary between what the evidence supports and what it does not.

Two tasks, two scoring rules

Track 1 · detectPredict the start and end of each noise event.
Track 1 · compareCheck event matches and how much time the labels overlap.
Track 2 · enhanceProduce a cleaner waveform, then run the fixed speech recognizer.
Track 2 · compareMeasure signal fidelity and word errors on the same clips.

Event F1 measures whether predicted events match reference events under the competition’s matching rule. The organizer describes a correct match using overlap within 20% of the reference event duration. A true positive is a matched event; a false positive is an unmatched prediction; a false negative is a missed reference event. Precision is the share of predictions that match. Recall is the share of reference events found. F1 balances precision and recall.

Segment Dice measures agreement between predicted and reference event labels over time. It is twice the overlap divided by the total predicted and reference event time. The two parts can move in opposite directions, so a small Dice increase does not automatically make a detector better. The organizer’s public page describes the official Track 1 overall score as an equal-weight average. The local experiment receipts below call the sum of event F1 and Segment Dice “Combined.” I label those values as local receipt scores; they are not official leaderboard scores.

Word error rate (WER) is the number of word substitutions, deletions and insertions divided by the number of reference words. Lower is better. A WER gain in percentage points is the noisy-audio WER minus the enhanced-audio WER, multiplied by 100. SI-SDR measures how closely an enhanced waveform preserves the clean reference signal; it is reported in decibels (dB), and higher is better. Track 2 combines mean SI-SDR with WER gain in percentage points. Track 1 and Track 2 combined scores use different units and must not be compared with each other.

The labels have different levels of detail

The challenge uses a timestamped noise-event layer over spontaneous speech. The released training set contains 90,637 segments, about 154.6 hours. Its three tiers describe what is known about event timing:

These are quality tiers within the challenge release, not three independent audio collections. The base VAANI speech corpus and the challenge’s noise-event annotations are related but have different schemas.

Track 1: keep the stronger event detector

The strongest recorded local full-manifest result remained the acoustic-boundary system. Candidate C, which used frozen ATST audio representations and produced event intervals, had a slightly higher Segment Dice in one evaluation but lower event F1. Its combined score was lower.

A simple per-clip selector also failed its promotion check

I screened a fixed rule that selected between the acoustic-boundary system and Candidate C using prediction agreement and boundary-confidence summaries. It used no reference labels to choose a system for an individual clip. The comparison used two separate released validation sets: REP-V2 has 512 population-matched clips; HARD-V2 has 256 clips selected as a stress test. A stress-test score is useful for finding weaknesses, but it is not an estimate of ordinary population performance.

Why I did not run another Silver-training experiment

The proposed Gold-plus-Silver acoustic refiner could not be run from the verified task-owned compute staging: the Silver timing manifest and audio were not staged there, and the exact acoustic checkpoint was available only in a prior local result directory. I did not transfer data or start a cluster job. The earlier Gold-only refiner had already reduced the recorded TRAIN-dev combined score by 0.002887, so repeating that recipe was not a sound substitute. This section reports a blocked experiment, not a negative Silver result.

Earlier boundary LDA, temporal-convolution proposals, fixed boundary snapping and another refiner also failed their recorded checks or regressed. Those are reasons not to repeat the same variants without a new hypothesis; they are not proof that every boundary method will fail.

Track 2: better words, worse signal score

The candidate blended 90% of the existing MP-SENet enhanced waveform with 10% of the original noisy waveform, using the same fixed blend for every clip. The 512-clip comparison reused one pinned validation set and the same local SraVaani speech recognizer. The recognizer was not changed between the noisy and enhanced audio.

The blend reduced recognition errors from 5,718 to 5,640 on these clips. But its SI-SDR was 2.0780 dB lower, and its combined score fell by 1.4574. Better recognition alone did not make it the better enhancement result under this scoring rule. I stopped the candidate before a larger run and did not submit it.

The WER values pool all 512 clips. SI-SDR uses only clips with an available clean reference. These two measurements therefore do not have identical clip coverage. The result is specific to this pinned validation split and recognizer; it does not establish performance on the private Phase 2 test set.

Validation controls and limits

  • REP-V2 and HARD-V2 were kept separate; the hard set was treated as a stress test.
  • The Track 2 candidate and unblended comparator used the same 512-clip manifest and scorer.
  • The Track 2 blend was fixed across clip types. It did not branch based on labels or audio class.
  • Track 2 output WAVs were reopened and checked before transcription. Their byte hashes were checked again afterward; all 512 matched.
  • The 3,178-clip Phase 2 blind package was not used for model choice or local scoring. No hidden labels or transcripts were inspected.
  • A grouped screen was used to avoid placing clips from the same putative source or speaker group on both sides of a split. Filename-derived groups are proxies, so they cannot prove that every speaker identity is unique.
  • Local manifest scores and the competition’s private Phase 2 leaderboard are separate evidence. The archived leaderboard note was not live-verified and is not reproduced as a current result here.

What I would carry forward

For event detection, I would keep the acoustic-boundary system as the current reference and require a new method to improve event F1 on the representative validation set without failing the hard-set check. For speech enhancement, I would require the signal-fidelity loss and word-error gain to be assessed together on the same frozen manifest before spending time on a larger run.

The most useful outcome was a cleaner experimental boundary: name each split, freeze the comparison, preserve the scorer, and label every score as local validation or leaderboard evidence. A number without that context is easy to overstate.
