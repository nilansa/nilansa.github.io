What did standard TTT-Embed achieve?

Using ten teacher-scored pairs per query, standard query-wise TTT-Embed improved the untouched dense retriever on the same 200 FiQA queries. The metric is nDCG@10 (ranking quality), not classification accuracy.

Presentation takeaway: Standard query-wise TTT-Embed improved this frozen retrieval baseline. However, none of our tested complementary-selection alternatives beat dense-top-10 feedback on nDCG@10.
01 / Protocol

What stayed fixed, and what changed?

Frozen components

Retriever: Qwen3-Embedding-0.6B (1,024-dimensional embeddings). Teacher: Qwen3-Reranker-4B. Corpus: all 57,638 FiQA documents.

One full-corpus retrieval yields a common top-50 pool. Each arm selects ten query–document pairs for P(Yes) scoring by the frozen teacher.

Inference-time optimization

A separate residual v is fitted for each query; the query and document encoder, reranker and index weights remain unchanged.

300 Adam steps, learning rate 0.01, λ = 0.3, teacher/student temperatures 0.02/0.05, residual application scale α = 0.5. A final full-corpus retrieval produces top-10 results.

v* = argmin_v KL[softmax(rᵢ / 0.02) || softmax(unit(x + v) · zᵢ / 0.05)] + 0.3 ‖v‖² x' = unit(x + 0.5 v*) ; rank all 57,638 documents by x' · z_d

x is the frozen query embedding, zᵢ fixed document embeddings, and rᵢ = P(Yes | query, document) from the teacher. The 300 optimizer steps reuse cached feedback; they do not entail 300 new reranker calls.

03 / Honest interpretation

Query-wise improvement is not task-wise generalization

The 46.18% → 50.60% comparison is a 200-query, query-wise experiment. The queries were previously exposed; it is not a clean unseen-query validation. No claim of a statistically confirmed global or cross-task improvement follows.

A different 648-query, five-fold task-wise TTT-Embed cross-fit used a shared residual trained on some FiQA queries and tested it on others: nDCG@10 0.46722 → 0.46313 (Δ −0.00408; paired 95% CI [−0.01072,+0.00262]). That test found no reliable held-out gain. The two designs answer different questions and should never be combined into one headline.
