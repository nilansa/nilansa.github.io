B-002 · macOS permission or approval dialogs stopping an agent

Status: Reported; the exact pending dialog/app must be identified before granting access. Owner: You, because macOS may require a local approval.

  1. On the Mac, open Apple menu → System Settings → Privacy & Security.
  2. If the request says the app wants to control the computer, open Accessibility. If it wants to see the screen, use Screen & System Audio Recording. If it wants to control another app, check Automation. Use Full Disk Access only for an explicitly necessary file-access request.
  3. Identify the exact requesting app (Claude Science, Claude Code, Codex, or another named app), review why it needs that permission, and enable only the needed permission.
  4. If the Mac displays an Allow / Deny prompt, approve only the intended trusted request. Quit and reopen the affected app if macOS asks. Retry the one blocked action and verify success.
  5. If there is no dialog or listed app, record the app name and exact on-screen error before making changes; do not enable permissions indiscriminately.
