How the sources are interpreted

Acceptance rates: Show an official historical year, track and denominator; if only parent-main statistics exist for a demo or workshop, the number is labeled parent main only. Missing or speculative rates are N/A. High historic acceptance is not a reliable substitute for scope fit.

Conference rankings: CORE/CCF metadata is a discovery filter, not an independent rating of an industry, demo or workshop track. For the full CS, speech, robotics, biomedical and ML catalogue, see Research atlas + venue rankings.

Discovery: Cross-check with Hugging Face AI Deadlines, CCFDDL, CS Deadlines, CSPicks and ML Contests. An aggregator is not an authoritative annual CFP.

Privacy: The page requests noindex and crawler opt-out, but it is hosted in a public GitHub repository. Anyone with the URL may read it. All actual private tasks and submissions belong in the private repository.
